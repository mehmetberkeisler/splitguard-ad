# Exact reproduction of the published numbers.
#
# This is the environment recorded on the GPU node before training
# (runs_gpu/gpu_environment.txt), not a set of versions anyone chose. Install
# it when you intend to reproduce a manuscript number, retrain an arm, or
# regenerate a released figure.
#
# For ordinary use of the package, install the package instead:
#
#     pip install -e .            # core, standard library only
#     pip install -e '.[all]'     # plus graph, training and figure extras
#
# scripts/check_environment.py compares a live interpreter against this set and
# exits non-zero on any mismatch. The node installed the CUDA 12.8 wheels, whose
# versions carry a +cu128 local suffix; the pins name the upstream versions so
# this file also installs on a CPU-only machine. To match the node exactly:
#
#     pip install --index-url https://download.pytorch.org/whl/cu128 \
#         torch==2.8.0 torchvision==0.23.0
#
# MONAI must be installed with --no-deps, and this is a property of the recorded
# environment rather than a convenience. monai 1.5.0 declares torch<2.7.0, while
# the node ran it against torch 2.8.0: scripts/gpu_setup.sh installs it with
# --no-deps onto the image's existing CUDA torch, so pip never saw the
# constraint. Installing this file as a whole therefore fails to resolve, and
# the honest reproduction is the same two-step the node used:
#
#     grep -v '^monai==' requirements-lock.txt > /tmp/lock.txt
#     pip install -r /tmp/lock.txt
#     pip install --no-deps monai==1.5.0
#
# MONAI is used only for its 3D ResNet-18 definition in the volumetric arm.
